# Homebrew tap of Apeiron

```bash
brew install efe-clk/apeiron/apeiron
```

This installs the `apeiron` command and its short name `ape`, built from the
source of the latest release. The formula is written by
[`packaging/manifests.py`](https://github.com/efe-clk/apeiron/blob/master/packaging/manifests.py)
for each release of [Apeiron](https://github.com/efe-clk/apeiron).
